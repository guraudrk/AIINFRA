# AX Platform Lab 개념서

> AI 시스템 엔지니어 직무에 필요한 개념을 이 프로젝트에서 실제로 한 일과 연결해 설명한 교과서입니다.
> 결과(무엇을 했나)는 `docs/study/` 면접 노트에, **원리(왜 그렇게 동작하나)**는 이 개념서에 있습니다.

## 읽는 법
각 개념은 같은 틀로 씁니다.

| 항목 | 내용 |
|---|---|
| **정의** | 한두 문장으로 무엇인지 |
| **왜 필요한가** | 이것이 없으면 어떤 문제가 생기는지 |
| **동작 원리** | 내부에서 실제로 무슨 일이 일어나는지 (단계별) |
| **이 프로젝트에서는** | 직접 만들고 측정한 것 |
| **흔한 오해** | 처음 배울 때 헷갈리는 지점 |
| **실무 포인트** | 데이터센터·고객사 환경에서 달라지는 점 |
| **면접 한 줄** | 질문을 받았을 때 첫 문장 |

비유는 노트와 같은 **"클러스터 = 병원"**을 씁니다. 노드 = 진료실, Pod = 환자, 스케줄러 = 접수처, GPU 노드 = MRI실, taint = "예약 환자만" 표지판입니다.

## 이 개념서의 원칙
- 프로젝트에서 **직접 측정한 숫자**를 예시로 씁니다. 측정하지 않은 것은 "일반적으로", "알려진 바로는"이라고 구분합니다.
- 실제 기업 환경(데이터센터 GPU 서버, OpenShift, 폐쇄망)과 이 프로젝트(kind, PC 한 대)의 차이를 숨기지 않습니다.
