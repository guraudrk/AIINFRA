## 1쪽

### 권한 기반 사내 AI 플랫폼을 GPU 쿠버네티스에 구축·운영하기
가상 제조사 "한빛정밀"의 설비 매뉴얼·품질 보고서·정비 이력을 사내 AI(sLLM + RAG + AI 에이전트)가 답하되, **직원의 역할에 따라 볼 수 있는 문서만 근거로 쓰는** 플랫폼을 PC 한 대 위 쿠버네티스 4노드에 구축하고, 보안·폐쇄망 설치·모니터링·백업·장애 대응·사이징까지 운영 업무를 재현했습니다.

### 왜
제조기업 IT팀에서 ERP 계정·권한을 운영하며 권한 요청 절차를 **"요청-검토-반영-이력 관리"**로 표준화했습니다. 생성형 AI가 사내 문서를 한꺼번에 읽게 되면 이 권한 원칙이 더 중요해진다고 생각했고, 에티버스그룹 AXhub가 강조하는 **"기존 사용자 권한 기준 조회 범위 제한"**을 인프라 엔지니어 관점에서 직접 만들어 보고 싶었습니다.

### 구성
| 계층 | 구성 | 핵심 개념 |
|---|---|---|
| 클러스터 | kind 4노드(관리·앱·GPU·데이터), Calico | GPU·데이터 노드에 taint를 걸어 허락받은 워크로드만 배치 |
| AI 서빙 | Ollama qwen2.5:3b, 임베딩 bge-m3(1024차원) | GPU 메모리 = 가중치 + KV 캐시 + 여유분 |
| 데이터 | PostgreSQL + pgvector, MinIO(S3 호환) | 원본은 오브젝트, 검색용 벡터는 DB |
| 앱 | FastAPI 게이트웨이(JWT, 도구 4개, 감사 로그), 채팅 화면 | 근거 없으면 LLM을 부르지 않고 "모름" |
| 보안 | **앱 필터 + DB 행 수준 보안(RLS)**, HTTPS(사내 CA), 기본 거부 NetworkPolicy | 한 겹이 뚫려도 다음 겹이 막는다 |
| 운영 | Prometheus·Grafana(DCGM 호환 GPU 지표), 백업 CronJob, 장애 주입 스크립트, 사이징 계산기 | 측정 → 알람 → 런북 |

### 같은 질문, 역할별로 다른 답
"3호기 E-203 대응 방법과 최근 정비 이력" → **작업자**는 안전 규정과 정비 요청서 초안만, **정비원**은 3호기 매뉴얼과 정비 이력 4건·부품 재고, **품질팀**은 품질 불량 보고서만, **관리자**는 전부를 받습니다. 자동 테스트 14개로 고정했습니다.

## 2쪽

### 측정한 결과
| 항목 | 결과 |
|---|---|
| 권한 | 앱 필터를 끈 배포에서도 품질 문서 유출 **0건**(감사 로그 + DB 직접 조회로 증명) |
| 폐쇄망 | 7.5GB 번들로 인터넷 차단 상태 **15분 21초** 재구축 |
| 네트워크 | 기본 거부 정책 적용 전 9개 열림 → 적용 후 **14/14** |
| 백업 | 테이블 삭제 후 복구 **RTO 48초 / RPO 36초** |
| 성능 | CPU 추론 동시 4개 처리량 34.8토큰/s, 8개에서 대기열로 TTFT p95 13초 |
| 사이징 | 가상 RFP(동시 100명): 32B FP8 = **70.6GB → L40S 2장**, KV 캐시가 가중치만큼 큼 |

### 직접 부딪히고 해결한 문제 (진단 → 원인 → 조치)
1. **모델 적재 교착**: 적재 Job이 서버에 접속을 못 함 → Service는 Ready Pod에만 연결되는데 Ready 조건이 "모델 있음" → NotReady에도 연결되는 관리용 Service 분리
2. **보안 강화가 배치를 깨뜨림**: RLS를 켜자 수집이 COPY 오류로 실패 → 트랜잭션 덕에 데이터는 무사, 임시 테이블 경유로 수정, Job 실패 알람 추가
3. **ingress-nginx 은퇴, MinIO 공식 이미지 배포 중단**: 저장소 상태를 확인하고 대안을 비교해 교체(Traefik, 소스 빌드 MinIO digest 고정)
4. **폐쇄망 반입 함정**: 멀티 아키텍처 저장 실패, docker save의 digest 변경 → 현장은 내부 레지스트리가 정석이라는 결론
5. **죽지 않는 장애**: Grafana가 CPU limit에 걸려 조용히 느려짐 → `kubectl top`으로 throttling 확인, 메모리 초과(OOMKilled)와의 차이 정리
6. **보안 사고 조사**: 권한 필터가 꺼진 배포 → 감사 로그와 DB 검증으로 "유출 없음"을 증거로 보고서 작성

### 한계와 다음 단계
GPU를 쿠버네티스에 실제로 붙이지 못해 SIMULATED로 진행했고, 실제 랙·스위치·BMC 작업은 해 보지 못했습니다. 입사 후 실제 GPU 서버 구축과 GPU Operator, 내부 레지스트리 기반 폐쇄망 구축을 가장 먼저 배우고 싶습니다.
