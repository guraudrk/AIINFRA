# CNC 3호기 설비 매뉴얼 (v2.0)

## 1. 설비 개요

- 설비 ID: CNC-03 / 모델: HBC-5X / 위치: B라인 / 설치: 2018년
- 기준값: 스핀들 최대 12,000rpm, 공압 0.6MPa, 절삭유 압력 0.3MPa

## 3. 경보 코드별 원인과 조치

### E-101 스핀들 모터 과부하

- 분류: 전기 / 심각도: high
- 예상 원인:
  1. 과도한 절삭 조건
  2. 공구 마모로 절삭 저항 증가
  3. 스핀들 베어링 손상
- 조치 순서:
  1. 가공 프로그램의 회전수·이송 속도를 확인한다
  2. 공구 마모 상태를 확인한다
  3. 무부하 회전 시 이음·진동을 점검한다
- 필요 부품: P-MEC-002(엔드밀 Ø10 초경)
- 안전 주의: 스핀들 정지 확인 후 공구에 접근한다.

### E-104 서보 드라이브 알람

- 분류: 전기 / 심각도: high
- 예상 원인:
  1. 서보 드라이브 과열
  2. 엔코더 케이블 노이즈
  3. 축 기계적 구속
- 조치 순서:
  1. 드라이브 표시 코드를 기록한다
  2. 드라이브 냉각팬 동작을 확인한다
  3. 축을 수동으로 이동해 걸림을 확인한다
- 필요 부품: P-ELC-004(서보 드라이브 냉각팬)
- 안전 주의: 드라이브 내부 콘덴서 잔류 전압 방전(5분) 후 작업한다.

### E-120 NC 통신 이상

- 분류: 전기 / 심각도: medium
- 예상 원인:
  1. DNC 케이블 불량
  2. 네트워크 설정 오류
- 조치 순서:
  1. NC 네트워크 설정을 확인한다
  2. 케이블 재체결 후 프로그램 재전송한다
- 필요 부품: P-ELC-003(PLC 통신 케이블(이더넷))
- 안전 주의: 프로그램 전송 중 가공 시작 금지.

### E-202 절삭유 압력 저하

- 분류: 윤활 / 심각도: medium
- 예상 원인:
  1. 절삭유 필터 막힘
  2. 절삭유 펌프 고장
  3. 절삭유 부족
- 조치 순서:
  1. 절삭유 탱크 유량을 확인한다
  2. 필터를 청소·교체한다
  3. 펌프 토출 압력을 확인한다
- 필요 부품: P-LUB-003(절삭유 필터), P-LUB-002(절삭유 펌프)
- 안전 주의: 절삭유 접촉 시 피부 보호구를 착용한다.

### E-207 윤활유 부족

- 분류: 윤활 / 심각도: low
- 예상 원인:
  1. 자동 윤활 탱크 유량 부족
  2. 윤활 펌프 고장
- 조치 순서:
  1. 윤활 탱크에 지정 윤활유를 보충한다
  2. 수동 윤활 버튼으로 토출을 확인한다
- 필요 부품: P-LUB-001(자동 윤활 펌프)
- 안전 주의: 지정 외 윤활유 혼용 금지.

### E-211 공압 압력 저하(공구 클램프)

- 분류: 공압 / 심각도: high
- 예상 원인:
  1. 공압 라인 압력 부족
  2. 레귤레이터 고장
- 조치 순서:
  1. 공압 게이지를 확인한다(기준 0.6MPa)
  2. 공구 클램프 동작을 수동으로 확인한다
- 필요 부품: P-PNE-001(공압 레귤레이터)
- 안전 주의: 클램프 압력 부족 상태로 가공하면 공구가 이탈할 수 있다.

### E-302 공구 마모 한계 초과

- 분류: 기계 / 심각도: low
- 예상 원인:
  1. 공구 수명 카운터 도달
- 조치 순서:
  1. 공구를 교체하고 공구 길이를 재측정한다
  2. 수명 카운터를 초기화한다
- 필요 부품: P-MEC-002(엔드밀 Ø10 초경)
- 안전 주의: 공구 교체 시 절삭날 보호 장갑 착용.

### E-308 도어 인터록 열림

- 분류: 안전 / 심각도: critical
- 예상 원인:
  1. 가공 중 도어 개방
  2. 인터록 스위치 고장
- 조치 순서:
  1. 도어 닫힘 상태를 확인한다
  2. 인터록 스위치 동작을 점검하고 불량 시 교체한다
- 필요 부품: P-SAF-002(도어 인터록 스위치)
- 안전 주의: 인터록 우회(점퍼) 운전 금지.

## 4. 정기 점검

- 일일: 절삭유·윤활유 유량, 칩 제거, 도어 인터록 확인
- 월간: 필터 차압, 안전장치 기능 시험, 전기 단자 조임
- 연간: 유압유 교환, 정밀도 측정, 안전 인증 점검
