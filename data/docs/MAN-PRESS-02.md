# 프레스 2호기 설비 매뉴얼 (v2.0)

## 1. 설비 개요

- 설비 ID: PRESS-02 / 모델: HBP-800 / 위치: A라인 / 설치: 2018년
- 기준값: 메인 유압 18MPa, 공압 0.5MPa, 유압유 온도 35~55℃

## 3. 경보 코드별 원인과 조치

### E-101 메인 모터 과부하

- 분류: 전기 / 심각도: high
- 예상 원인:
  1. 연속 고속 운전으로 모터 과열
  2. 클러치 미끄럼으로 부하 증가
  3. 열동 계전기 설정값 불량
- 조치 순서:
  1. 운전 정지 후 모터 표면 온도를 비접촉 온도계로 확인한다(80℃ 이하까지 냉각)
  2. 열동 계전기 트립 여부와 설정값(정격 전류 105%)을 확인한다
  3. 클러치 공기압과 라이닝 마모를 점검한다
  4. 재기동 후 무부하 운전 10분으로 전류값을 기록한다
- 필요 부품: P-ELC-001(메인 모터 열동 계전기)
- 안전 주의: 모터 단자함은 반드시 메인 차단기 OFF와 잠금·표지(LOTO) 후 개방한다.

### E-102 비상정지 회로 작동

- 분류: 전기 / 심각도: critical
- 예상 원인:
  1. 작업자가 비상정지 버튼을 누름
  2. 비상정지 스위치 접점 불량
  3. 안전 릴레이 배선 단선
- 조치 순서:
  1. 비상정지가 눌린 위치를 확인하고 현장 안전을 확인한다
  2. 버튼 복귀 후에도 경보가 남으면 접점 블록 도통을 측정한다
  3. 안전 릴레이 입력 LED 상태를 확인한다
- 필요 부품: P-ELC-002(비상정지 스위치 접점 블록)
- 안전 주의: 원인을 확인하기 전에 비상정지를 해제하거나 우회 배선하지 않는다.

### E-115 PLC 통신 이상

- 분류: 전기 / 심각도: medium
- 예상 원인:
  1. 이더넷 케이블 접촉 불량
  2. 스위칭 허브 전원 이상
  3. PLC IP 충돌
- 조치 순서:
  1. PLC 통신 포트 LED(Link/Act)를 확인한다
  2. 케이블을 재체결하고 통신 재시도한다
  3. HMI 진단 화면에서 IP 충돌 이력을 확인한다
- 필요 부품: P-ELC-003(PLC 통신 케이블(이더넷))
- 안전 주의: 운전 중 케이블 분리는 금형 동작 이상을 유발할 수 있으니 정지 상태에서 작업한다.

### E-201 유압유 온도 상승

- 분류: 유압 / 심각도: medium
- 예상 원인:
  1. 유압유 냉각기 팬 정지
  2. 유압유 부족
  3. 릴리프 밸브 상시 개방으로 발열
- 조치 순서:
  1. 유압유 온도계를 확인한다(정상 35~55℃, 65℃ 이상 시 정지)
  2. 냉각기 팬 회전 여부를 확인한다
  3. 유면계로 유량을 확인하고 부족 시 ISO VG46을 보충한다
- 필요 부품: P-HYD-005(유압유 냉각기 팬), P-HYD-006(유압유 ISO VG46 (20L))
- 안전 주의: 고온 유압유에 의한 화상에 주의한다. 배관 접촉 금지.

### E-203 유압 압력 저하

- 분류: 유압 / 심각도: high
- 예상 원인:
  1. 유압 필터 막힘으로 흡입 불량
  2. 유압 펌프 씰 마모로 내부 누유
  3. 압력 센서 고장(오검출)
  4. 릴리프 밸브 설정 이탈
- 조치 순서:
  1. 운전을 정지하고 메인 압력 게이지 값을 기록한다
  2. 유압 필터 차압 표시기를 확인하고 적색이면 필터 엘리먼트를 교체한다
  3. 펌프 주변 누유 흔적을 점검하고 누유 시 씰 키트를 교체한다
  4. 게이지 값은 정상인데 경보가 뜨면 압력 센서 출력(4~20mA)을 측정한다
  5. 릴리프 밸브 설정 압력을 확인하고 기준값으로 재조정한다
  6. 조치 후 무부하 운전 15분 동안 압력 안정 여부를 확인한다
- 필요 부품: P-HYD-003(유압 필터 엘리먼트), P-HYD-001(유압 펌프 씰 키트), P-HYD-002(유압 압력 센서), P-HYD-004(릴리프 밸브)
- 안전 주의: 유압 라인은 잔압 제거(어큐뮬레이터 방출) 후 분해한다. 고압 유압유 분사로 인한 부상 위험.

### E-210 공압 압력 저하(클러치·브레이크)

- 분류: 공압 / 심각도: high
- 예상 원인:
  1. 공장 공압 라인 압력 부족
  2. 공압 레귤레이터 고장
  3. 솔레노이드 밸브 누설
- 조치 순서:
  1. 공압 게이지를 확인한다(기준 0.5MPa)
  2. 레귤레이터 설정과 드레인 상태를 점검한다
  3. 솔레노이드 밸브 배기음으로 누설 여부를 확인한다
- 필요 부품: P-PNE-001(공압 레귤레이터), P-PNE-002(공압 솔레노이드 밸브)
- 안전 주의: 공압 저하 시 브레이크 성능이 떨어지므로 슬라이드를 하사점에 두고 점검한다.

### E-301 금형 높이 이상

- 분류: 기계 / 심각도: medium
- 예상 원인:
  1. 슬라이드 조정 모터 브레이크 마모
  2. 금형 교체 후 다이하이트 미설정
- 조치 순서:
  1. 다이하이트 표시값과 금형 사양서를 비교한다
  2. 슬라이드 조정 후 인칭 운전으로 하사점을 확인한다
- 필요 부품: P-MEC-001(슬라이드 조정 모터 브레이크)
- 안전 주의: 인칭 운전 중에는 금형 영역에 손을 넣지 않는다.

### E-305 안전 광커튼 차단

- 분류: 안전 / 심각도: critical
- 예상 원인:
  1. 작업자 신체가 위험 영역에 진입
  2. 광커튼 오염·정렬 불량
  3. 수광부 고장
- 조치 순서:
  1. 위험 영역에 사람이나 물체가 없는지 확인한다
  2. 투·수광부 렌즈를 청소하고 정렬 표시등을 확인한다
  3. 지속 시 수광부를 교체한다
- 필요 부품: P-SAF-001(안전 광커튼 수광부)
- 안전 주의: 광커튼을 비활성화한 상태로 생산하는 것은 금지되어 있다(안전 규정 3조).

## 4. 정기 점검

- 일일: 유압·공압 게이지, 누유, 이음 확인 (작업 시작 전)
- 월간: 필터 차압, 안전장치 기능 시험, 전기 단자 조임
- 연간: 유압유 교환, 정밀도 측정, 안전 인증 점검
